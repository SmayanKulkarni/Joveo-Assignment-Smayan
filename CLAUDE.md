# Skills

For any task involving LangChain, LangGraph, Deep Agents, Managed Deep Agents, RAG, agent middleware/persistence/HITL, the langgraph CLI, parallel subagent fan-out, or agent evals, invoke the `langchain-router` skill first and load only the skills it points to. Do not answer framework API questions from memory.

# Code style

Write readable code. Add short comments that explain *why* a block exists or does what it does, not what each line does. Comment only where the reason isn't obvious, and keep the code uncluttered. Never put long header comments or docstring essays at the top of files.
