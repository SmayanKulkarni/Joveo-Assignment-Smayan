# What focus changes

Type: grilling
Status: resolved
Assignee: smayankulkarni05
Blocked by: none

## Question

HLD §12 defers to this LLD what each `--focus` value changes. What does it change in Request & Plan, and does the CLI need to change for the spec's `--focus salary` example?

## Answer

Decided by grilling.

- **`focus` changes nothing in the search.** The same Postings answer every Dimension and Stats are cheap Python, so narrowing the fetch would save nothing and would weaken the rest of the Market Brief. `plan` doesn't read it.
- **Brief uses it** to order and emphasise Insights (⏳ Brief LLD).
- **Alias.** The spec's example is `--focus salary`, but the CLI's choices are `Dimension` values, where that would be rejected. The CLI accepts `salary` as an alias for `compensation`.
